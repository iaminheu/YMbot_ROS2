# SRC 主要目录解析

## arm_vr_motion

机器人的 VR 遥控驱动模块

## chassis_control

底盘控制 / 移动底座控制

## control

控制

## inspire_hand

五指灵巧手驱动包

## ObbecSDK_ROS2

欧博智联（Obbec）SDK 机器人驱动包（ROS2 版）

## realsense-ros

英特尔 RealSense 深度相机 ROS2 驱动包

## remote_operate_pkg

远程操作功能包 / 远程遥控包

## start_robot

一键启动机器人所有模块

## vr_receiver_tcp

VR 数据 TCP 接收模块 / VR 手柄数据接收器
