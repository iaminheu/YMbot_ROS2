# 一、一句话总结

这是一个 **ROS 2 Python 手势抓取检测节点**

作用：

**接收数据手套（左手 / 右手）的关节角度 → 计算、滤波、判断是否****握拳 / 抓取** → 输出 0（松开）/ 1（抓取）。

---

# 二、完整功能

1. **接收手套数据**
   订阅 `/left_hand/joint_data`、`/right_hand/joint_data`
2. **角度转换 + 手指排序**
   把手套 0\~1000 数值 → 转成弧度，并调整手指顺序
3. **EMA 滤波**
   让数据平滑、不抖动
4. **抓取判断算法**
   根据**手指弯曲速度 + 弯曲幅度**判断：* 快速握拳 → **输出 1（抓取）**
   * 快速张开 → **输出 0（松开）**
5. **防抖（消抖）**
   连续判定多次才切换状态，防止误触
6. **发布结果**
   * `/left_hand/grasp01`、`/right_hand/grasp01`
   * 0 = 松手，1 = 抓取

---

# 三、核心算法逻辑（最重要）

## 抓取判断靠 3 个条件：

1. **弯曲幅度足够大**
   `level > ABS_ON（0.02）`
2. **弯曲速度足够快**
   `rise > DELTA_ON（0.015）`
3. **连续满足 N 帧（防抖）**
   `DEBOUNCE_ON = 2`

满足 → **判定抓取（1）**

## 松开判断：

1. **张开速度足够快**
   `fall < -DELTA_OFF（-0.012）`
2. **连续满足 N 帧**

满足 → **判定松开（0）**

---

# 四、程序运行流程

1. 启动节点
2. 订阅左右手手套数据
3. 数据转换：0\~1000 → 弧度
4. EMA 平滑滤波
5. 计算**弯曲幅度 + 弯曲速度**
6. 状态机判断：抓取 / 松开
7. 防抖确认
8. 发布 grasp01（0/1）

---

# 五、关键话

### 订阅（输入）

* `/left_hand/joint_data`
* `/right_hand/joint_data`

### 发布（输出）

* `/left_hand/grasp01`     →  0/1 抓取状态
* `/right_hand/grasp01`
* `/left_hand/joint_angles`  → 手指角度
* `/right_hand/joint_angles`

# 六、这个节点在系统中的作用

你们的机器人**手爪抓取的大脑**：

* VR 控制手臂运动
* **这个节点判断你有没有握拳**
* 握拳 → 机器人夹取

# 七、总结

该节点是**机器人数据手套手势抓取检测模块**，基于 ROS 2 实现。

通过接收柔性手套的手指关节数据，经单位转换、指数平滑滤波（EMA）后，根据**手指弯曲幅度与运动速度**实现抓取 / 松开状态识别。

节点加入**防抖消抖机制**，提升识别稳定性，最终输出二值化抓取状态（0/1），为机器人手爪夹持控制提供手势指令。
