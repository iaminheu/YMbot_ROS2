# 一、一句话总结

这是一个 **机器人关节电机键盘控制程序**

作用：

**通过键盘按键，单独控制机器人的【左手 / 右手 / 躯干】任意一组电机，进行微小角度转动调试，属于底层硬件直接控制工具。**

---

# 二、这个程序的用途（非常明确）

1. **机器人关节调试工具**
   工程师调试机械臂时用，不用写代码，按键盘就能单个关节动。
2. **底层电机直接控制**
   不经过 ROS、MoveIt、VR，**直接驱动电机**。
3. **支持三组电机独立控制**
   * 左手（7 个电机）
   * 右手（7 个电机）
   * 躯干 / 脖子（6 个电机）
4. **安全微调**
   每次只动很小角度（0.15°），防止撞机。

---

# 三、整体运行流程（一眼看懂）

1. 启动程序
2. 选择控制部位：
   * `l` → 左手
   * `r` → 右手
   * `b` → 躯干
3. 自动初始化对应电机
4. 启动**键盘监听线程**
5. 按按键 → 电机微动
6. 按 **\`** （反引号）退出

---

# 四、逐模块详细解释（通俗易懂）

## 1. 全局变量

cpp

运行

```
int joint_control_command[14];
char keycode_positive[14] = {'q','w','e',...};
char keycode_negative[14] = {'a','s','d',...};
```

作用：

* 14 个按键对应 14 个关节
* 正数键（q/w/e...）：**关节 + 角度**
* 负数键（a/s/d...）：**关节 - 角度**

---

cpp

运行

```
int main() {
  选择 l / r / b
  启动键盘线程
  执行电机控制
}
```

功能：

* 让用户选择控制左手 / 右手 / 躯干
* 自动加载对应电机 ID
* 启动键盘监听
* 启动电机控制

---

## 3. KeyboardFunction () 键盘监听线程

cpp

运行

```
void KeyboardFunction()
```

功能：

* 不阻塞主程序，**后台持续读键盘**
* 按下按键 → 给 `joint_control_command` 赋值
  * 按 `q` → 关节 0 +
  * 按 `a` → 关节 0 -
  * 按  → 停止
  * 按 **\`** → 退出

# 五、MotorFunction () 核心电机控制（最重要）

cpp

运行

```
int MotorFunction(vector<int>& id_array)
```

## 功能分 4 步：

### ① 扫描 CAN 总线，寻找电机

程序自动找：

* 11\~19：躯干电机
* 31\~39：左手电机
* 41\~49：右手电机

### ② 初始化电机（CSP 位置模式）

* 启动电机
* 读取当前角度
* 设置为目标位置

### ③ 主循环（20ms 刷新一次）

cpp

运行

```
while(exit_flag == 0)
{
  根据 joint_control_command 控制电机+角度 或 -角度
  发送角度指令
  打印当前角度
}
```

### ④ 退出时关闭所有电机

安全关闭，防止电机发烫。

# 六、按键对应关系

每个关节对应两个按键：

**正数键（+ 角度）** 和 **负数键（- 角度）**

关节编号 → 按键：

plaintext

```
0: q / a
1: w / s
2: e / d
3: r / f
4: t / g
5: y / h
6: u / j
7: i / k
8: o / l
9: p / z
10:x / c
11:v / b
12:n / m
13:1 / 2
```

选择：

* `l` → 左手 31\~37
* `r` → 右手 41\~47
* `b` → 躯干 11,12,13,14,21,22

# 八、总结

该程序是机器人**关节电机底层调试与控制工具**，通过 CAN 总线直接驱动伺服电机，支持左手、右手、躯干三组电机独立控制。

程序采用双线程架构：键盘监听线程负责实时捕获按键指令，电机控制线程负责位置闭环控制。

用户可通过按键对各关节进行微小角度调整，适用于机械臂零位校准、运动范围测试、硬件故障排查等场景，是机器人底层硬件开发与调试的核心工具。
