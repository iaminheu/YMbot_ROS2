# 一、一句话总结

这是一个 **ROS 2 + MoveIt Servo 右臂 VR 位姿跟踪控制节点**

作用：

**接收 VR 手柄位姿 → 实时控制机器人右臂末端跟随运动，并自带【奇异点急停保护 + 自动恢复】功能，保证机械臂运动安全。**

---

# 二、和左臂代码的区别（关键）

* 左臂：`pose_tracking_left_arm`
* **本段：`pose_tracking_right_arm`（右臂）**
* **增加了：Servo 急停监控 + 奇异点保护 + 自动恢复**
  这是**增强版、安全版、可实际运行的工业级代码**。

---

# 三、核心功能

1. **VR 控制右臂末端**
   你动 VR 手柄 → 右臂**精准、实时、丝滑跟随**
2. **相对运动模式**
   以第一次 VR 位置为**零点**，不跳变、不飞臂
3. **奇异点（死点）保护**
   机械臂快伸到极限 → **自动急停**，防止炸机
4. **自动恢复**
   退出奇异点后 → **自动恢复控制**，不用重启
5. **高频 100Hz 控制**
   运动流畅无卡顿

---

# 四、最重要的新增功能：奇异点急停保护

cpp

运行

```
void servoStatusCallback(...)
{
  if (msg->code == ServoStatus::HALT_FOR_SINGULARITY)
  {
    is_servo_halt = true;  // 急停
  }
  else
  {
    连续5次正常 → 恢复
  }
}
```

作用：

* 机械臂进入**奇异点（死点）**
* Servo 自动停止
* 本节点**停止发指令**
* 你把手柄往回拉 → 退出奇异点
* **自动恢复控制**

这是**真实机器人必备的安全机制**！

# 五、完整运行流程（最清晰）

1. 启动节点
2. 等待 15 秒 → **获取右臂初始位姿**
3. 切换 Servo → **POSE 位姿模式**
4. 订阅 **VR 右臂位姿**
5. 订阅 **Servo 状态（监控急停）**
6. 第一个 VR 数据 = **零点**
7. 实时计算 **VR 相对位移**
8. 叠加到机械臂姿态 → **发布目标位姿**
9. **如果奇异点发生 → 暂停发布**
10. 退出奇异点 → **自动恢复**

# 八、总结

该节点是**机器人右臂 VR 沉浸式位姿跟踪控制模块**，基于 ROS 2 与 MoveIt Servo 实现。通过接收 VR 设备输出的末端位姿，计算相对运动偏移，实现机械臂对 VR 手柄的实时、高精度、平滑跟随。

节点新增**奇异点检测与急停保护机制**，实时监控 Servo 运行状态，当机械臂接近奇异位置时自动暂停指令发布，避免硬件损坏；退出奇异状态后自动恢复控制，大幅提升系统稳定性与安全性。

该节点是双臂机器人 VR 遥操作系统中**右臂运动控制的核心组件**。
